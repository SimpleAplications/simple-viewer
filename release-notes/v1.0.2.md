A small corrections release.

## Download

- **Simple-Setup.exe**: the installer. No administrator rights needed.
- **Simple-portable.zip**: no install; unzip anywhere and run `Simple.exe`.

The files with `1.0.2` in the name are the same downloads under their versioned names. To update, run the new installer over the old one.

Windows may show "Windows protected your PC" because the installer is not digitally signed yet: choose **More info**, then **Run anyway**. To check your download, compare its SHA-256 with `SHA256SUMS.txt`.

## Changed

- **"Hide from screenshots and screen sharing" is now described correctly.** With the option on, the window is left out of screenshots, recordings and screen sharing, which show whatever is behind it instead. The earlier text said the window appears black and mentioned Windows Recall, which has not been verified.
- **The third-party notices now list the libraries built into the included FFmpeg.**

## FFmpeg

Simple uses libraries from the [FFmpeg](https://ffmpeg.org) project under the LGPL, shipped as separate, unmodified DLLs. `ffmpeg-source-n8.1.3-17-gc389840894.tar.gz` is the FFmpeg source code of the included build. See `THIRD-PARTY-NOTICES.txt` in the app's folder.
