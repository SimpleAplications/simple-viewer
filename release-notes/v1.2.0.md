Reiks Viewer now speaks seven languages.

## Download

- **ReiksViewer-Setup.exe**: the installer. No administrator rights needed.
- **ReiksViewer-portable.zip**: no install; unzip anywhere and run `ReiksViewer.exe`.

The files with `1.2.0` in the name are the same downloads under their versioned names. To update, run the new installer over the old one.

Windows may show "Windows protected your PC" because the installer is not digitally signed yet: choose **More info**, then **Run anyway**. To check your download, compare its SHA-256 with `SHA256SUMS.txt`.

## New

- **Languages:** English, Spanish, Swedish, French, German, Portuguese and Italian. The app follows the language of Windows; you can pick another under Options → Language.
- **The name follows the language too:** Reiks Viewer, Reiks Visor, Reiks Visare, and so on. The program file and downloads keep one name.
- **The installer's standard pages** are available in the same languages. Its own extra options (Open with, default app, firewall rule) are still in English.
- **The website** is available in English, Spanish and Swedish.

Changing the language sets the picture adjustments (brightness, contrast and so on) back to neutral.

Not every translation has been checked by a native speaker yet. Spotted a wrong or awkward translation? Please open an issue; all the texts are in one small file.

## Fixed

- **Jumping backwards in some `.ts` and `.m2ts` videos could leave the player stuck.** It happened in transport streams with very few keyframes. The player now goes back until it finds one.

## Described more exactly

The website, the README and the texts in the app now say more precisely what Reiks Viewer does and where its limits are:

- "Hide from screenshots" relies on a Windows feature. It cannot stop a camera pointed at the screen or software made to get around it, and it has not been tested against Windows Recall.
- Windows keeps records of its own that the app has no say over: its recent files list, the folder the Open dialog was last in, and error reports if the app crashes.
- The installer and the zip are built from the public code on GitHub's servers. The FFmpeg libraries inside are an unmodified public build, checked by checksum, not built there.
- Installing for yourself needs no administrator rights; installing for all users does.
- Reiks Viewer is tested on Windows 11. Windows 10 and HEIC photos from iPhones have had little or no testing so far.

## FFmpeg

Reiks Viewer uses libraries from the [FFmpeg](https://ffmpeg.org) project under the LGPL, shipped as separate, unmodified DLLs. `ffmpeg-source-n8.1.3-17-gc389840894.tar.gz` is the FFmpeg source code of the included build. See `THIRD-PARTY-NOTICES.txt` in the app's folder.
