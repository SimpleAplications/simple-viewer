Reiks Viewer now speaks seven languages.

## Download

- **ReiksViewer-Setup.exe**: the installer. No administrator rights needed.
- **ReiksViewer-portable.zip**: no install; unzip anywhere and run `ReiksViewer.exe`.

The files with `1.2.0` in the name are the same downloads under their versioned names. To update, run the new installer over the old one.

Windows may show "Windows protected your PC" because the installer is not digitally signed yet: choose **More info**, then **Run anyway**. To check your download, compare its SHA-256 with `SHA256SUMS.txt`.

## New

- **Languages:** English, Spanish, Swedish, French, German, Portuguese and Italian. The app follows the language of Windows; you can pick another under Options → Language.
- **The name follows the language too:** Reiks Viewer, Reiks Visor, Reiks Visare, and so on. The program file and downloads keep one name.
- **The installer's pages** are available in the same languages.
- **The website** is available in English, Spanish and Swedish.

Changing the language sets the picture adjustments (brightness, contrast and so on) back to neutral.

Spotted a wrong or awkward translation? Please open an issue; each language is a single small file.

## FFmpeg

Reiks Viewer uses libraries from the [FFmpeg](https://ffmpeg.org) project under the LGPL, shipped as separate, unmodified DLLs. `ffmpeg-source-n8.1.3-17-gc389840894.tar.gz` is the FFmpeg source code of the included build. See `THIRD-PARTY-NOTICES.txt` in the app's folder.
