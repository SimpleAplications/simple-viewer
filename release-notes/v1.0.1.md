A privacy and safety release.

## Download

- **Simple-Setup.exe**: the installer. No administrator rights needed.
- **Simple-portable.zip**: no install; unzip anywhere and run `Simple.exe`.

The files with `1.0.1` in the name are the same downloads under their versioned names. To update from 1.0.0, run the new installer over the old one.

Windows may show "Windows protected your PC" because the installer is not digitally signed yet: choose **More info**, then **Run anyway**. To check your download, compare its SHA-256 with `SHA256SUMS.txt`.

## New

- **Decoding is restricted to local files.** FFmpeg may only use the `file` protocol, so nothing inside a file can make Simple open a network address.
- **Only known formats are accepted.** FFmpeg's playlist, script and other unneeded file readers are refused.
- **Hide from screenshots and screen sharing** (Options → Privacy): the window shows as black in screenshots, recordings, screen sharing and Windows Recall.
- **Hide file names** (Options → Privacy): the title bar and taskbar show "Simple" instead of the file's name.
- **Quick hide:** press `H` to pause and blank the window at once; press it again to return. The key can be changed in Options.
- **Files opened through the Open dialog** are no longer added to Windows' recent files list.
- **Check for updates** (F1): opens the download page in your web browser. Simple itself still never goes online.
- **Installer:** an optional Windows Firewall rule that blocks Simple from the network (all-users install only).

## Also in this release

- From this version on, the downloads are built from the public source by GitHub Actions, and each file carries a build provenance attestation: `gh attestation verify Simple-Setup.exe --repo SimpleAplications/simple-viewer`.

## FFmpeg

Simple uses libraries from the [FFmpeg](https://ffmpeg.org) project under the LGPL, shipped as separate, unmodified DLLs. `ffmpeg-source-n8.1.3-17-gc389840894.tar.gz` is the FFmpeg source code of the included build. See `THIRD-PARTY-NOTICES.txt` in the app's folder.
