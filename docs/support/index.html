Help and support

Reiks Viewer is made by Reiks Apps. This page answers the common questions and says how to reach us.

Report a problem or ask a question

Open an issue on GitHub; a free GitHub account is needed. Say which version you use (it is shown in the F1 window), what you did and what happened. Issues are public, so don’t attach private pictures or personal details.

A file doesn’t open

Press F1 in Reiks Viewer to see every format it opens. Whether a particular file opens also depends on what is inside it: a damaged file, or one made with a rare codec, may not.

Windows warns when I install it

The installer from GitHub is not digitally signed yet, so Windows may show “Windows protected your PC”: choose More info, then Run anyway. The copy from the Microsoft Store does not show this warning.

Updates

The Microsoft Store installs the updates of the copy from the Store. For the installer from GitHub, “Check for updates” in the F1 window opens the download page; run the new installer over the old one. Reiks Viewer itself never connects to the internet, so it does not tell you about updates by itself.

Security problems

Please don’t report a security problem in a public issue. The security policy describes how to report it privately.

What Reiks Viewer keeps and what goes over the network: see the privacy policy.
