Ayuda y soporte

Reiks Visor lo hace Reiks Apps. Esta página responde a las preguntas habituales y explica cómo contactarnos.

Comunicar un problema o hacer una pregunta

Abre una incidencia en GitHub; hace falta una cuenta gratuita de GitHub. Indica qué versión usas (aparece en la ventana F1), qué hiciste y qué pasó. Las incidencias son públicas, así que no adjuntes imágenes privadas ni datos personales.

Un archivo no se abre

Pulsa F1 en Reiks Visor para ver todos los formatos que abre. Que un archivo concreto se abra depende también de su contenido: un archivo dañado, o uno hecho con un códec poco común, puede no abrirse.

Windows avisa al instalarlo

El instalador de GitHub aún no está firmado digitalmente, así que Windows puede mostrar «Windows protegió su PC»: elige Más información y luego Ejecutar de todas formas. La copia de Microsoft Store no muestra este aviso.

Actualizaciones

Microsoft Store instala las actualizaciones de la copia de la Store. Para el instalador de GitHub, «Buscar actualizaciones» en la ventana F1 abre la página de descarga; ejecuta el nuevo instalador sobre el anterior. Reiks Visor nunca se conecta a internet por sí mismo, así que no te avisa de las actualizaciones.

Problemas de seguridad

Por favor, no comuniques un problema de seguridad en una incidencia pública. La política de seguridad explica cómo comunicarlo de forma privada.

Lo que Reiks Visor guarda y lo que pasa por la red: consulta la política de privacidad.

Reiks Visor se ofrece tal cual, sin garantía.
