Hjälp och support

Reiks Visare görs av Reiks Apps. Den här sidan svarar på vanliga frågor och berättar hur du når oss.

Rapportera ett problem eller ställ en fråga

Öppna ett ärende på GitHub; du behöver ett gratis GitHub-konto. Skriv vilken version du använder (den visas i fönstret F1), vad du gjorde och vad som hände. Ärendena är offentliga, så bifoga inga privata bilder eller personuppgifter.

En fil går inte att öppna

Tryck på F1 i Reiks Visare för att se alla format den öppnar. Om en viss fil går att öppna beror också på vad den innehåller: en skadad fil, eller en som gjorts med en ovanlig codec, kanske inte öppnas.

Windows varnar när jag installerar

Installationsprogrammet från GitHub är ännu inte digitalt signerat, så Windows kan visa ”Windows skyddade datorn”: välj Mer information och sedan Kör ändå. Kopian från Microsoft Store visar inte den här varningen.

Uppdateringar

Microsoft Store installerar uppdateringarna för kopian från Store. För installationsprogrammet från GitHub öppnar ”Sök efter uppdateringar” i fönstret F1 nedladdningssidan; kör det nya installationsprogrammet över det gamla. Reiks Visare ansluter aldrig till internet på egen hand, så den säger inte till om uppdateringar.

Säkerhetsproblem

Rapportera inte ett säkerhetsproblem i ett offentligt ärende. Säkerhetspolicyn beskriver hur du rapporterar det privat.

Vad Reiks Visare sparar och vad som går över nätverket: se integritetspolicyn.

Reiks Visare tillhandahålls i befintligt skick, utan garanti.
