Integritetspolicy

Reiks Visare, från Reiks Apps. Senast uppdaterad 15 oktober 2026.

Kort sagt

Reiks Visare samlar inte in, sparar inte och skickar inte personuppgifter. Den har inget konto, ingen reklam, ingen analys och ingen egen kraschrapportering.

Det som stannar på din dator

Reiks Visare skriver en enda fil: dina inställningar (tangenter, fönsterfärg, språk, uppspelningsval, samt skrivaren, pappersstorleken och storleksvalet du senast skrev ut med). Den sparas i %APPDATA%\ReiksViewer\settings.json, eller i appens egen datamapp om den installerades från Microsoft Store. Ingenting om filerna du öppnar skrivs ner: ingen historik, ingen lista över senaste filer, inga miniatyrer.

Det som går över nätverket

Appens egen kod har inga nätverksfunktioner, och dess avkodare är begränsade till lokala filer. Knappen ”Sök efter uppdateringar” i fönstret Format (F1) öppnar nedladdningssidan i din webbläsare, eller appens sida i Microsoft Store, och bara när du klickar på den.

Om du öppnar en fil från en nätverksenhet eller en molnsynkroniserad mapp är det Windows eller ditt synkprogram som flyttar datan. Utskrifter går via Windows eget utskriftssystem, som talar med din skrivare, över ditt nätverk om det är en nätverksskrivare.

Installera från Microsoft Store

När du installerar Reiks Visare från Microsoft Store sköter Microsoft nedladdning, installation och uppdateringar enligt sin egen sekretesspolicy. Microsoft ger utvecklare sammanställda rapporter, till exempel hur många som installerat appen och sammanfattningar av krascher som Windows har rapporterat till Microsoft enligt dina diagnostikinställningar i Windows.

Frågor

Frågor om integritet kan du ställa genom att öppna ett ärende på github.com/reiks-apps/reiks-viewer/issues. Ärendena där är offentliga.

Om policyn ändras publiceras den nya versionen på den här sidan med ett nytt datum.

Reiks Visare tillhandahålls i befintligt skick, utan garanti.
