Reiks Visare

Dina bilder och videor förblir dina. Reiks Visare visar dem bara för dig, och det är allt den gör.

Ladda ner för Windows

Gratis · öppen källkod · ansluter aldrig till internet · Windows 10 eller 11, 64-bitars

Det Reiks Visare aldrig gör

Vissa visare och spelare gör mer än att visa dina filer: de söker efter uppdateringar, samlar användningsstatistik, sparar historik eller bygger ett bibliotek. Reiks Visare gör inget av det.

  • Ansluta till internetIngen telemetri, ingen användningsstatistik, inga kraschrapporter, inga uppdateringskontroller, inga uppslagningar på nätet. Dess egen kod har inga nätverksfunktioner alls. Dess avkodare är begränsade till lokala filer och avvisar spellistor och strömningsformat, för att en särskilt utformad fil inte ska kunna styra den till en webbadress.
  • Spara vad du öppnarIngen historik, ingen lista över senaste filer, ingen miniatyrcache, inget bibliotek eller index över dina mappar.
  • Titta in i dina bilderIngen ansiktsigenkänning, ingen taggning, ingen AI, ingen ”förbättring” i molnet. Reiks Visare skickar ingenting från dina filer till någon.
  • Ändra dina filerDen skriver aldrig till dina bilder, videor eller deras mappar: inga betyg, inga taggar, inga dolda sidofiler.
  • Köra i bakgrundenIngen tjänst, ingen autostart, ingen ikon i meddelandefältet. När du stänger den är den borta.
  • Be om någontingInget konto, ingen inloggning, ingen reklam, inga medföljande extraprogram. Att installera den bara för dig själv kräver inga administratörsrättigheter.

Vad den gör

En bildruta i taget, åt båda håll

Tryck på X eller Z för att gå exakt en bildruta framåt eller bakåt. Håll nere för att fortsätta, snabbare ju längre du håller. Varje bildruta avkodas helt innan den visas, så ett hopp lämnar ingen utsmetad bild.

Bilder, GIF:ar och video tillsammans

Öppna en fil och bläddra genom allt annat i mappen med piltangenterna. Zooma med mushjulet, dra för att panorera, rotera och spegla.

Privat även på skärmen

Låt Windows hålla fönstret utanför skärmbilder, inspelningar och skärmdelning, som då visar det som finns bakom. Dölj filnamn i namnlisten och aktivitetsfältet. Tryck på H för att tömma fönstret direkt.

Bildreglage

Ljusstyrka, kontrast, mättnad, gamma och värme för allt på skärmen, även pausad video. Påverkar bara visningen: dina filer ändras aldrig.

Dina tangenter, din färg

Välj tangenter för spela, nästa, föregående och bildrutestegning under Alternativ, och fönstrets färg i menyn Vy. Texten växlar mellan vitt och svart för att förbli läsbar.

Spela en hel mapp

Låt den gå vidare till nästa fil när en video tar slut, i ordning eller blandat, en gång eller om och om igen. Eller upprepa en enda video.

Skärmbilderna visar appen på engelska; den finns också på svenska.

Lita inte bara på vårt ord

  1. Blockera den och se själv. Neka Reiks Visare all nätverksåtkomst i Windows-brandväggen; när du installerar för alla användare erbjuder installationsprogrammet att lägga till den regeln åt dig. Allt fungerar som förut, eftersom den aldrig behövde någon anslutning.
  2. Läs koden. Reiks Visare har öppen källkod. Installationsprogrammet och zip-filen byggs från den koden på GitHubs egna servrar, öppet. GitHub signerar för var och en ett intyg som anger vilken kod den byggdes från, så att vem som helst kan kontrollera att en nedladdning verkligen kommer från den publicerade koden. FFmpeg-biblioteken som följer med byggs inte där: de är ett oförändrat offentligt bygge, angivet med sin kontrollsumma i upplysningarna.
  3. Kontrollera din nedladdning. Varje version anger SHA-256-kontrollsumman för varje fil.

Det Reiks Visare inte kan styra över

Windows sparar vissa uppgifter på egen hand, och dem kan Reiks Visare inte påverka. När du öppnar en fil genom att dubbelklicka på den i Utforskaren kan Windows lägga till den i sin lista över senaste filer (Inställningar → Anpassning → Start → ”Visa nyligen öppnade objekt”). Reiks Visare ber Windows att inte lägga till filer som öppnas via dess egen Öppna-dialog i den listan, men Windows kan ändå komma ihåg vilken mapp dialogen senast visade. Om Reiks Visare skulle krascha kan Windows felrapportering registrera kraschen, precis som för andra appar. Windows diagnostikdata och Recall är också Windows-inställningar, under Sekretess och säkerhet.

”Dölj från skärmbilder” bygger på en funktion i Windows. Windows tillämpar den på de vanliga sätten att fånga skärmen: Print Screen, Skärmklippverktyget, skärminspelare och skärmdelning i mötesappar. Den kan inte hindra en kamera som riktas mot skärmen eller program som är gjorda för att kringgå den, och vi har inte testat den mot Windows Recall.

Om du öppnar en fil från en nätverksenhet eller en molnsynkad mapp är det Windows eller ditt synkprogram som flyttar datan över nätverket, precis som för andra appar. Och som alla mediespelare måste Reiks Visare avkoda det en fil innehåller: en avsiktligt skadad fil kan få den att krascha eller bete sig oväntat, så håll den uppdaterad och var försiktig med filer från källor du inte litar på.

Vid normal användning är den enda fil Reiks Visare skriver dina alternativ: dina tangenter, fönsterfärg, språk samt uppspelnings- och integritetsval, i %APPDATA%\ReiksViewer\settings.json. Den innehåller ingenting om dina filer. Avinstallationen tar bort den; om du använder den portabla zip-filen tar du själv bort den mappen.

Installation

Windows kan varna dig första gången. Installationsprogrammet är ännu inte digitalt signerat, så Windows kan visa ”Windows skyddade datorn”. Välj Mer information och sedan Kör ändå.

För att kontrollera att din nedladdning är hel och stämmer med den publicerade filen, jämför dess SHA-256-kontrollsumma med SHA256SUMS.txt. I PowerShell: Get-FileHash ReiksViewer-Setup.exe

Att installera bara för dig själv kräver inga administratörsrättigheter; att installera för alla användare gör det. Installationsprogrammet kan lägga till Reiks Visare i Utforskarens lista ”Öppna med”. För att uppdatera kör du ett nyare installationsprogram över det gamla; ”Sök efter uppdateringar” i appen (F1) öppnar nedladdningssidan i din webbläsare, och själva appen förblir offline.

Reiks Visare är testad på Windows 11. Den bör även fungera på Windows 10, men det har ännu inte testats.

Öppen källkod inuti

Reiks Visare avkodar bilder och video med bibliotek från FFmpeg-projektet, licensierade under GNU Lesser General Public License. FFmpeg ingår som separata, oförändrade DLL-filer som du får ersätta med ditt eget bygge. FFmpeg-källkoden för det medföljande bygget publiceras med varje version, och de fullständiga upplysningarna finns i THIRD-PARTY-NOTICES.txt i appens mapp.
